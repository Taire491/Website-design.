# Nathaniel Hassan — Creative Portfolio Projects

**Digital Designer | Web Designer | Multimedia Creative**

This package contains three self-initiated fictional portfolio concepts designed to demonstrate creative capabilities. They are not paid client engagements and the fictional products/brands do not represent live businesses.

## 01 — Urban Bites / Brand identity
Visual identity system for a modern neighborhood restaurant: primary and alternate wordmarks (SVG), color and typography system, sample menu, social campaign graphics, food photography, and a multi-page brand guide PDF.

## 02 — Nexora / Website design & front-end build
Responsive B2B technology landing page concept built with HTML, CSS, JavaScript, and SVG. Includes responsive navigation, an abstract CSS 3D-style hero illustration, dashboard UI mockup, solution sections, and a front-end-only demo form.

## 03 — Elevate / Promotional video
30-second 16:9 motion-graphics brand film plus a 15-second 9:16 social cutdown, thumbnail, original synthesized soundbed, storyboard timeline, and campaign production notes.

## How to view
1. Open `index.html` in a modern browser to view the portfolio landing page.
2. Open `projects/nexora/index.html` to view the responsive website concept.
3. Open the PDFs in `projects/urban-bites/` and `docs/` for the brand guide and case-study deck.
4. Open the MP4 files in `projects/elevate/` to view the finished videos.

## Important presentation guidance
Describe these as **independent concept projects** or **self-initiated portfolio work**. Do not describe the fictional brands as real clients, and do not claim revenue, conversion, or business outcomes. Replace sample contact details, brand names, imagery, and copy before adapting any concept for a real client.

## Interview narrative
- Urban Bites demonstrates visual identity, typography, layout systems, print/digital applications, and brand consistency.
- Nexora demonstrates responsive implementation, UI hierarchy, interface interactions, and front-end fundamentals.
- Elevate demonstrates concept development, visual storytelling, motion graphics, kinetic typography, sound design, and multi-format delivery.
